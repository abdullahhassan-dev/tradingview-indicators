# 🎯 TradingView Smart Money Indicators

Professional-grade TradingView indicators combining Smart Money concepts, institutional order blocks, CVD analysis, and liquidity detection for high win-rate trading.

## 📊 Indicators Included

### 1. **Smart Money Order Blocks** 
- Detects institutional buy/sell zones
- Shows where smart money accumulates
- Predicts bounce points with high accuracy

### 2. **CVD (Cumulative Volume Delta)**
- Tracks buyer vs seller pressure
- More reliable than RSI alone
- Identifies strength of moves

### 3. **Liquidity Levels**
- Finds where institutions have trapped retail traders
- Shows support/resistance zones
- Helps avoid false breakouts

### 4. **Volume Profile**
- Visualizes volume distribution at each price level
- High volume zones = stronger levels
- Improves TP/SL placement

### 5. **Entry/Exit Signals**
- Combines EMA + Order Blocks + CVD
- Green signals = BUY confirmation
- Red signals = SELL confirmation

## 🚀 How to Use

1. **Copy the Pine Script** from `indicators/` folder
2. **Open TradingView** → Create New Chart
3. **Paste Script** in Pine Editor
4. **Add to Chart** and customize settings
5. **Set alerts** for trading signals

## ⚙️ Indicator Settings

```
EMA Periods: 7, 25, 99
Order Block Sensitivity: Medium
CVD Lookback: 50 candles
Volume Profile Bins: 20
Alert Notifications: ON
```

## 📈 Best Practices

✅ Use on **1H, 4H, Daily** timeframes (most reliable)  
✅ Combine with **liquidity levels** for TP/SL  
✅ Wait for **CVD confirmation** before entry  
✅ Use **3:1 risk/reward minimum**  
✅ Trade with **trend**, not against it
